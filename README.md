# Kishan Copilot

Kishan Copilot is an AI-powered farming assistant that helps farmers with:

- Weather updates
- Crop suggestions
- Market insights
- Disease detection
- Voice assistance in local languages

## Features

- Real-time farming insights
- Crop management assistance
- Smart advisory system
- Multilingual support
- Future WhatsApp integration

## Tech Stack

- Python
- Flask
- HTML/CSS/JS

## Run Project

```bash
# 1. Install dependencies
pip install -r requirements.txt
 
# 2. Set API keys
export ANTHROPIC_API_KEY=sk-ant-...        # Required — all AI features
export OPENWEATHER_API_KEY=your_key_here   # Optional — live weather (mock data used if absent)
 
# 3. Run
python app.py
# → http://localhost:5000
```

Open:

```text
http://127.0.0.1:5000
```
