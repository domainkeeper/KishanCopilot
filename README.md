# Kishan Copilot

Kishan Copilot is an AI-powered farming assistant that helps farmers with:

- Weather updates
- Crop suggestions
- Market insights
- Disease detection
- Voice assistance in local languages

## Features

- Real-time farming insights
- Crop management assistance
- Smart advisory system
- Multilingual support
- Future WhatsApp integration

## Tech Stack

- Python
- Flask
- HTML/CSS/JS

## Run Project

```bash
pip install -r requirements.txt
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
